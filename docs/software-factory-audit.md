See the [operator guide](software-factory.md) for limits, credential placement, setup, reproduction and the full external handoff. No App private key or Git write credential enters compute. The trusted source-fetch broker on the Node temporarily receives a single-repository read credential; no credential enters an Agent workspace.

The Server database backs up authorization and audit records, not Node disk images. Linux root/loop-device access is required for the hard disk provider. Docker's shared-kernel implementation is limited to trusted operators/code; VM/microVM isolation for hostile public tenants, macOS/Windows Nodes and local workspace port previews are not implemented. Original repository CI/Preview integrations remain authoritative, including the possibility that drafts have no preview.

GitHub CI initially found two integration omissions: the Server terminology guard also rejected coding-checkout vocabulary, and the Pi Docker smoke still expected a native checkout after native computer access was disabled. The guard now permits only the factory's specific coding vocabulary in named integration sources, with regressions for retired community models. Broker-only Run completion no longer requests a native files archive; factory receipts remain separate. Fresh local images now pass the complete Pi restart/cancellation smoke, and 1,283 root tests pass across 200 files.

The separate CodeQL result must also be reviewed, even when its upload workflow is green. Its initial eight annotations cover command execution, Node connection/receipt network and file flows, and a file-read race. The race is corrected with no-follow file handles, inode-based type checks and a bounded read. The other annotated flows cross intentional boundaries: the trusted root daemon runs fixed Docker/disk operations, approved arbitrary shell commands run inside fresh restricted containers, private Node state identifies the paired Server, and bounded authenticated Server responses become private credentials or retained receipts. These controls require independent security review at the final SHA. No query is disabled and no alert is suppressed or dismissed by this PR.
