# L4 0.1.1

L4 brings independent installations and isolated servers to a common web, PWA, Telegram and Capacitor client. Each server has its own Worker, D1 database, private files bucket and Durable Objects; backups use a separate destination. Cloudflare and celld Compose deployments are included under MIT.

- Fix generated PWA startup by substituting the executable asset assignment instead of its lint comment.
- Preserve exact HTML asset paths on Cloudflare so the offline shell can be cached without a redirect.
- Verify the generated service worker precaches the public shell and leaves private API and cross-origin traffic on the network.
- Publish the complete installation deployment bundle and checksums alongside the server installer files.

Telegram and automatic Cloudflare provisioning require operator credentials. App Store/native push distribution, Gitrew and cross-product embedding remain later work.
