# L4 0.2.5

Data is now one shared space for documents, databases and canvases. Inbox has its own menu, Agents has a directory for starting private conversations, and settings use focused editing dialogs.

- Keep the compact 72px Server rail with Inbox first. Data opens one menu with Documents, Databases and Canvases groups, shared bookmarks and direct resource links. Create each resource from the overview, including on phones.
- Filter Inbox by channels, human direct messages or Agent chats. The main area shows the selected filter and its conversation count; an empty filter remains distinct from an entirely caught-up Inbox.
- Browse Agents, search profiles and open a direct message. Authorized managers can create or edit Agents in dialogs from the directory, Server menu or settings. Public directory profiles do not expose management instructions. Invite and management actions follow current permissions.
- The account panel spans the rail and section menu. Section and conversation headers share a 48px height, and the larger Server icon responds to hover and open state. Mobile navigation retains separate, scrollable context menus.
- Edit channel categories and move channels through labeled dialogs. Agent settings show a list with create/edit dialogs. Settings opens without focusing search, and Escape closes the active nested dialog before the settings screen.
- Create documents immediately as Untitled and name them later. Creating another document first saves the current draft; a failed save keeps it open, and repeated clicks do not create duplicates. Delete is available only when a document is selected.
- Server updates retry temporary Cloudflare Worker upload failures with bounded backoff and reconcile update state before retrying. Permanent errors remain visible. The verified backup and existing Server resources are preserved.

Validation includes 683 unit tests, lint, type checks, builds, independent Server integration, self-host and local-stack checks. An isolated Git-built Cloudflare Server Preview verified document creation and persisted renaming. Browser checks covered Agent editing and DM opening, category dialogs, nested Escape, permission-restricted navigation, light/dark layouts and phone/desktop widths. Chromium, Firefox and WebKit plus contrast, reflow, reduced-motion and localization checks passed; physical devices and live model execution were not exercised in this UI pass.

This release adds no schema migrations. The official site, Shell, standalone Server, portable amd64 runtime, VPS installer and version-pinned Docs share version 0.2.5. Customer Servers remain pinned until their operators select the update under Settings → Deployment → Updates and complete the verified backup/update flow. Native iOS/macOS packaging remains frozen.
