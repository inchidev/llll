# L4 0.2.0-alpha.3

This release fixes first-owner setup through the official Shell for already deployed Servers.

- Recover the matching Server’s owner claim from the installer session when reloading a bookmarked setup route. Consume an explicit claim fragment before mirroring navigation in Shell, and accept a later handoff even when the Server is already open.
- Wait for the Server Client’s readiness before sending navigation. Preserve the initial setup fragment instead of replacing it with the same path without its claim.
- Keep owner credentials out of saved bookmarks and localStorage, and reject installer claims for other Server origins. The Server’s existing one-time claim validation and local authentication are unchanged.

The fix applies in the Shell; operators can finish setup of an existing Server without redeploying it. The `server-v1` schema lineage is unchanged. Native iOS/macOS packaging remains frozen.
