# L4 0.3.11

This release makes Telegram a full Shell: open L4 from [@L4_agent](https://t.me/L4_agent), keep your Servers there, create new ones and get notifications from them in Telegram. Landing, Shell, installer, Server, portable runtime and Docs share **0.3.11**. It stays on the `server-v2` lineage and adds one migration, `0003_telegram_notifications`. Customer Servers update only when their operator chooses an update.

## Telegram Shell

- @L4_agent opens the Shell on **My Servers**, like the installed app. It keeps clear of Telegram's controls, the notch and the home indicator, including the embedded Server.
- **Create → Cloudflare** offers **Continue in browser**, because Cloudflare sign-in does not work reliably inside Telegram. When the Server is ready, **Open in Telegram** next to it brings it back to the Telegram Shell.
- You sign in on each Server with its own account, as on the web. L4 keeps no Telegram accounts.

## Telegram notifications

- In the Telegram Shell, **Settings → Telegram notifications** asks Telegram to let @L4_agent message you, then sends mentions, direct messages, Live sessions and email as a short message with an **Open** button.
- Messages name only the Server, never what was said. The Server stores an opaque delivery token and never learns your Telegram ID; llll.gg keeps no list of subscriptions.
- Blocking the bot, or turning the switch off, removes the subscription. Telegram notifications need no Web Push keys and work next to Web Push on your other devices. See [Telegram](https://llll.gg/docs/guides/telegram).

## Git

- **Server settings → Git → Gitea** names the token scopes L4 needs.

## Update to this release

A Cloudflare Server that keeps Cloudflare access updates from Server settings → Deployment → Updates by itself. A Docker Server updates by its image tag in Coolify or Docker Compose; the VPS installer uses `llll upgrade`. The update applies `0003_telegram_notifications`, which adds three columns to push subscriptions; the Telegram notifications switch appears once the Server runs 0.3.11.
