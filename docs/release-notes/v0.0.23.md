# L4 0.0.23

A Task's Agent keeps the conversation when it starts working on the box. No migration.

## Agents

- **The Task's earlier conversation.** A turn that starts without its transcript is told the asking Member's own earlier turns on the Task, oldest first: what they said and what the Agent answered. This happens, for example, on the first turn on the Task's box after the idea was talked through without one. Before, it started from a clean slate and found the idea again from the Task text. At most 12 turns and 24,000 characters are told. Another Member's turns are never included, and private context from a different authority is still never restored.

## Updating

- No migration, no binding change. Hosted Servers update in place. The box image is unchanged since 0.0.21.
