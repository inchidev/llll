# L4 0.3.0

Unified naming (`llll` worker for llll.gg, `llll-*` generated server workers, single `SETUP_TOKEN`, `APP_NAME` display name) and git-push deployment: push to `main` deploys llll.gg with migrations, PRs get isolated `pr-N.dev.llll.gg` previews deleted on close. Server previews use shared staging (`pnpm staging:setup`); per-PR buckets removed. Landing cleaned up (mark-only logo, `/servers` page, `llll.gg/<server_id>` routing).

Existing installs: server-worker names stay as provisioned (new servers get `llll-*` names); VPS deployments must rename `ADMIN_SETUP_TOKEN` to `SETUP_TOKEN` and may drop `ADMIN_WORKSPACE` in favor of `APP_NAME`.
