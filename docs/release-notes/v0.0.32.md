# L4 0.0.32

A new box on L4 Compute starts on a busy machine, and starts about a minute sooner. No migration.

## Software Factory

- **A new box gets time to start.** The daemon asked for a new box's health once, and the box had 10 seconds to start listening. On a busy Small machine its code takes 7 to 17 seconds to load, so some boxes failed to start. The daemon now asks again, once a second, for up to 90 seconds.
- **The box image is already loaded.** The 0.0.32 box templates carry the box image already loaded into Docker. A box no longer spends about a minute loading it at start (llll-cloud's `scripts/compute-template.mjs`).

## Updating

- No migration, no binding change. Hosted Servers update in place, once their Agents are not working. L4 Compute needs the 0.0.32 box templates.
