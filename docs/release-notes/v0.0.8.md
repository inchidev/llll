# L4 0.0.8

Search moves out of the list of views. This release has no database migration. Take the pre-update backup as usual.

## Navigation

- **Search sits in the section header.** The search button was above **Inbox** and looked like one more view. It is now at the right of the section menu's header, beside the section title, such as **Tasks**.
- **Search is in the Server menu too.** Pages with no section menu have no such header, so the Server menu now has **Search and commands**, showing its shortcut. ⌘K (Ctrl+K on Windows and Linux) still opens it anywhere in the Server.

## Docs

- [Create a Server on Cloudflare](https://llll.gg/docs/get-started/create-on-cloudflare) describes the installer as it is now on llll.gg: the form and the deployment fill the whole screen, and the deployment ends on **Finish setup on your Server**.

## Updating

- Cloudflare: no resource, binding or Durable Object changes.
- VPS and Docker: redeploy the new image as usual.
