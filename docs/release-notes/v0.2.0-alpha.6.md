# L4 0.2.0-alpha.6

Server names and icons now follow the Server's current settings throughout the Client and Shell. The Server and Shell also share the completed monochrome styling in both light and dark modes.

- Publish the configured name, public icon URL and appearance revision through `/.well-known/llll`. Serve only the current Server icon anonymously at `/.well-known/llll/icon`; other files and private settings retain their existing authorization.
- Refresh appearance in the Server rail, My servers, saved connections, Cloudflare inventory and login branding. Settings changes propagate through the embedded Client; background refresh keeps saved metadata current and retains cached appearance when a Server is unavailable. Deleting an icon restores the initials fallback.
- Share neutral surfaces, text contrast, focus indicators, tabs and controls across the Server and Shell. Make unchecked switches visible, label account switches, improve small chat metadata and keep phone text fields readable.
- Simplify authentication to a flat layout with a compact phone header. Keep long settings save messages and actions visible at narrow widths, and move notifications above persistent save bars with safe-area support.

The Shell update is published at llll.gg. Existing standalone Servers must be updated by their operator to this release to provide the new public appearance contract and Server styling. Their selected versions remain pinned until updated.

The `server-v1` schema lineage and Server-local authentication remain unchanged. Native iOS/macOS packaging remains frozen.
