# L4 0.1.0

First L4 foundation release with a fresh Git history and separate installation/server migration baselines.

- Independent installations with multiple isolated server Workers, D1 databases, files buckets and Durable Objects.
- Common Nuxt client with installation groups, server switching, rich chat, threads, tasks, mail, data and apps inherited from Discoflare, plus a measured virtual timeline.
- Autonomous password accounts, optional shared OIDC identity, optional Telegram browser/Mini App login, one-use PKCE client connections and account recovery keys.
- Separate backup destinations, installation/server exports, scheduled bound-bucket backups and backups before managed updates.
- Cloudflare artifacts and celld Docker Compose generation; Capacitor iOS packaging and static PWA updates.

Telegram and Cloudflare provisioning require operator credentials. Native push relays/App Store distribution, Gitrew headless integration, OpenRivers/AfterPrompt embedding and cross-server DMs are not part of this release.
