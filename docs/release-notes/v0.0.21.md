# L4 0.0.21

A box takes every turn the Server may send. No migration.

## Software Factory

- **Every turn fits the box.** 0.0.20 named why a box refused a turn: the Run's steps. An execution policy allows up to 2,048 steps (256 by default) and the runtime in the box took 100. A partner Agent's instructions may be 200,000 characters and it took 16,000. The runtime now takes both, and a test builds the widest turn the Server can send and requires the box to admit it.

## Updating

- No migration, no binding change. Hosted Servers update in place. L4 Compute and paired Nodes need the 0.0.21 box image.
