# L4 0.2.0-alpha.4

The Cloudflare tab at `/create` now shows your account’s L4 Servers and lets you create another without getting stuck on the previous deployment’s completion screen.

- List Servers discovered through L4 deployment markers in the selected Cloudflare account. Refresh their public readiness status and distinguish ready Servers, unfinished owner setup and unavailable origins.
- Keep owner setup available for matching unfinished installations during the installer session. Open ready Servers without repeating password setup instructions.
- Show separate expiry countdowns for Cloudflare access and the installer session. Reconnect after expiry to refresh the account or create another Server; existing Servers continue running.
- Retain public Server addresses on this device, clearly mark the saved list when disconnected, and keep private owner claims out of bookmarks and localStorage.

Server authentication and the `server-v1` schema lineage are unchanged. Customer Servers keep their selected release until their operator updates them. Native iOS/macOS packaging remains frozen.
