# L4 0.0.16

L4 Compute recovers a Task whose box is gone, and a partner's Agent starts on Sonnet. No migration.

## Software Factory

- **A Task whose L4 Compute box is gone gets a new box.** When a box's sandbox ended or was removed, every later turn of its Task waited on the silent box. Now a box whose own Node has been silent for three minutes, or is disabled, is let go on llll.gg and the turn asks for a new box, starting from the Task's pinned source. What the box had published stays.
- **A partner's Agent starts on Sonnet.** The default model a partner sets tries Claude Sonnet before the dearer Opus and GPT-5 without its mini or nano, never a free or batch variant, and is always among the models the Server keeps.

## Updating

- No migration, no binding change.
