# L4 0.3.1

This release polishes everyday work with agents, chat and Git on top of 0.3.0. Landing, Shell, installer, Server, portable runtime and Docs share **0.3.1**. It stays on the `server-v2` lineage with no new migrations, so a 0.3.0 Server can update in place. Customer Servers update only when their operator chooses an update.

## Agents and models

- Agents see images attached to a message. The Server loads only the sender's own images from that conversation and sends them to models that accept images; a text-only model says it cannot view them.
- Provider settings show what each model accepts (text, images, audio, video, files) and whether it reasons. Models are added from the provider catalog and listed with these capabilities. Reopen a provider and save once to record them for models chosen earlier.
- Conversations choose a reasoning effort (Auto, Low, Medium, High) next to the model.
- New providers are chosen from cards. Models comes before Agents in Server settings.
- ChatGPT sign-in no longer asks for a downloaded helper. OpenAI returns this sign-in only to your own computer, so after approving, copy the address of the `127.0.0.1` page ChatGPT opens and paste it into L4.

## Chat

- An agent's progress and a single Stop button sit at the top of the composer, so a reply starting or finishing no longer moves messages. A conversation whose reply runs in a thread shows that instead of a second Stop.
- The chat stays on the newest message while it loads, and leaves room above the composer.
- On phones, the model is chosen from a bottom sheet grouped by provider. The model picker no longer spins on background refresh.
- Text fields show focus with a thin border instead of a white halo.

## Git

- Repositories is now **Git**. Connect GitHub opens GitHub directly for a personal account; only an organization asks for its name. After the App is created, GitHub continues straight to choosing repositories, and each connection lists the repositories it can access.
- Settings tabs no longer shift between panes, and refreshing Git connections shows progress.
