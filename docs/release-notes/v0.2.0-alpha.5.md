# L4 0.2.0-alpha.5

The Shell logo now opens **My servers** instead of the marketing landing, keeping navigation within your saved Server connections.

- Show this device’s saved Server names, addresses and unread counts at `/servers`. Open a saved Server through its UUID route or remove its local bookmark. An empty list offers Add a server; removing a bookmark does not delete the Server or its Account.
- Highlight the logo on My servers and the plus button in `/create`. Keep loaded Clients mounted while showing the list, and prevent background Client navigation from replacing it. Support direct loads, trailing slashes and history navigation; legacy `/servers?server=…` connection links still open the installer.
- Temporarily hide the landing’s screenshot tabs and Apps promotion, including their navigation and footer anchors, until the new Server styling and real screenshots are ready.
- Replace the landing’s ambiguous Open L4 action and Play icon with Connect a server, opening the Connect tab consistently.

Server authentication and the `server-v1` schema lineage are unchanged. Customer Servers keep their selected release until their operator updates them. Native iOS/macOS packaging remains frozen.
