# L4 0.0.22

A partner's Agent publishes what it builds, and a creator sees why it stopped. No migration.

## Partners

- **The partner's secrets reach its game.** What a partner leaves with secrets/set becomes a secret of each game's Project, bound to the same hosts, and those hosts open in the Project's network. This happens when the Project is made and again before each build, so an older Project catches up. AfterPrompt's creator agent can now publish from its box with the placeholder, and the box puts the key in only on its way to AfterPrompt.
- **A box turn names its placeholders and repository.** The Agent's instructions list the Project secrets as placeholders with their hosts (never a value), the repository its checkout came from, and the plain settings a partner left.
- **Why the Agent stopped.** When a Run fails or is cancelled, the Member who started it reads "The Agent stopped:" and the reason, instead of a private-result notice.

## Updating

- No migration, no binding change. Hosted Servers update in place. The box image is unchanged since 0.0.21.
