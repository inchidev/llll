# L4 0.2.9

Fresh Server setup recovers from expired Cloudflare authorization, model selection stays explicit, and task results can reach their task and report channel without granting Agents general task-editing access.

- The installer offers Reconnect after stale authorization and reports provisioning progress while a step is running. Operators can pause an incomplete deployment and resume its existing Server identity and resources. Starting another deployment retains the paused attempt; it does not delete infrastructure or backups.
- Basic storage is identified as KV storage when R2 is unavailable. Unclaimed Servers retain their chosen name through setup and discovery.
- A provider catalog or Workers AI binding no longer silently selects a default model. Operators explicitly choose the Server default; unavailable selections produce actionable errors. An explicitly configured deployment model remains available, and importing OpenRouter preserves that operator choice. Models known to lack tool support are excluded from Agent choices.
- Members with Manage roles can choose an Agent's initial Role. Agent creation and editing show loading and unavailable model states, prevent duplicate submissions, and close reliably after saving. Creating a custom Role asks for its name.
- Task admission identifies whether the initiating Member or assigned Agent lacks permission and checks report-channel access before inference. The Agent's Execute tasks grant can finalize the same assigned task without granting Create and update tasks; subsequent manual edits, reassignment and revoked access remain protected.
- Completed Runs record task-update and report-delivery status separately from computation. Run details expose safe delivery errors and let the original initiator retry delivery under current authorization. Retries reuse the saved result and avoid duplicate reports.
- Embedded Client startup preserves direct navigation. Thread titles resolve mentions to readable names, and model requests receive current UTC time and the Server timezone. Agents can use the current-time tool when needed.

Validation includes 863 tests across 153 unit/component files, lint and type checks, migration/domain checks, Server and web builds, isolated R2 and Basic KV integration, self-host installation/cold restore, and local-stack checks. All required GitHub and Workers Builds checks passed on the feature PR, and its Web Preview reported the tested commit. Desktop Chrome verified Agent creation with an initial Role and direct navigation. The existing local Docker Server was backed up and updated with its data preserved. Fresh-account Cloudflare OAuth/R2/TLS provisioning and live model inference remain separate acceptance gaps.

This release appends migration 0014 within `server-v1` for durable Run delivery records. Keep a verified pre-update backup. The official web, Shell, installer, standalone Server, portable amd64 runtime and version-pinned Docs share version 0.2.9. Customer Servers remain pinned until their operators complete the backup/update flow. Native iOS/macOS publication remains frozen.
