# L4 0.2.1

L4 moves the current 0.2 release line from named alpha prereleases to ordinary versioned releases. This release contains the same application changes as 0.2.0-alpha.8, with a shared version of 0.2.1 for the official site, Shell, standalone Server and Docs.

- Continue the 0.2.x line with incremental releases. The stable release channel can discover subsequent 0.2.x releases from an installed 0.2.1 Server.
- Include the web/embedded Client update banner with retry and draft preservation, mobile Server menu, narrow-screen composer, responsive Overview save/reset controls and keyboard-accessible panel tabs from 0.2.0-alpha.8.
- Publish matching immutable Cloudflare bundles, portable amd64 runtime, VPS installer and version-pinned Docs.

Moving from an alpha Server to 0.2.1 requires an explicit operator update. The Updates screen remains informational; it does not install Worker updates. Existing standalone Servers stay pinned until their operator updates them. The `server-v1` schema and local Accounts, sessions and permissions are unchanged.

The VPS/celld installer retains its documented experimental status and verification limits. Native iOS/macOS packaging remains frozen. Clients predating the web update banner may need their existing Server tabs closed once to load the upgraded Client.
