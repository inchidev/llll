# L4 0.0.28

A partner's creator answers the Agent's requests in their own chat, common package hosts need no request, and Runs get room for real builds. No migration.

## Partners

- **Requests in the partner's chat.** `tasks/get` lists the Agent's open requests on a Task (`requests`: a network window, a plan, a publication or a merge, with what it asks in plain fields and never a secret value), and `tasks/decide` approves or rejects one as the Member, through the same decision the Run page makes.
- **Package hosts.** A partner names hosts its game Projects reach without asking (`hosts` in the seed, `secrets/set`, or `hosts/set`), checked strictly and at most 20. The Agent's box brief lists them.
- **A turn that ran out of time while waiting** now says which request it waited for, instead of "Run cancelled".

## Agents

- **Room for builds.** A Run may use 20 million tokens by default (up to 100 million) and an Agent 200 million in 24 hours (up to 1 billion). Every model call resends the conversation, so the old 2 million ended a build after about 30 calls. A Server that saved its own limits keeps them.

## Updating

- No migration, no binding change. Hosted Servers update in place. The L4 Compute box did not change, so its 0.0.27 templates stay.
