# L4 0.0.25

Watch the Agent's box screen live, and the Agent tests its work in a real browser. One migration.

## Software Factory

- **A screen and a browser in the box.** Every Docker and L4 Compute box has a virtual display and Chromium with Playwright, so an Agent opens a web game, takes screenshots and reads its console instead of testing with Node alone. WebGL draws in software.
- **Watch the box.** On L4 Compute, a person who may read a Task gets a link to watch its box screen live (`POST /api/tasks/:id/preview`, and `tasks/preview` for partners). The stream comes from voxl in a viewer container beside the box, with no network and no input. A link opens for 30 minutes; an open stream lasts while the box runs. Watching takes no turn and keeps no box running. Only the Server and the partner's site may frame it.
- **Idle saves and the screen.** An idle L4 Compute box removes its viewer before it saves its disk, and a restored box starts a new one, so earlier links stop opening.

## Partners

- `tasks/get` says `preview: true` while a Task's box can be watched; `tasks/preview` answers `{ url, expiresAt }`.

## Licensing
