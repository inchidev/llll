# L4 0.0.24

An idle L4 Compute box gives its machine back, an Agent starts a talked-through build itself, and a Task's screenshots reach the Agent. No migration.

## Software Factory

- **Billed while it works.** After 15 minutes without a turn, an L4 Compute box saves its Task disk as a checkpoint in its private repository in L4, in the same format Cloudflare boxes use, and its machine is released. The next turn starts a new machine in about a minute and restores the checkpoint, so the Agent continues where it was. A box whose save fails keeps its machine. Before, an idle box kept its machine, and its bill, until its Task was Done.
- **Lost boxes keep their work.** A box whose machine went away restores from its last checkpoint instead of the pinned source.

## Agents

- **The Agent starts the build.** In a Task's turn without a box (talk first), the Agent has `start_build`. When the person asks to build or confirms the plan, it starts the build on the box itself, with the conversation. Before, every message stayed a talk turn until the person found a separate Build button.

## Partners

- **Screenshots reach the Agent.** A screenshot given with `tasks/create`, or with a message through the new `attachments` of `tasks/message`, joins the Task and reaches the Agent's turn as an image. A model that reads images sees it; another gets the Server's image description. Before, the turn only named the file.
- **Model, effort and progress.** `models/list` answers the Server's models and efforts for a conversation picker. `tasks/create` and `tasks/message` take a `model` and an `effort` that stay with the Task's conversation. While the Agent works, `tasks/get` carries `activity`: the running turn's start, its box, its model calls and its latest steps.

## Models

- **A silent model keeps its connection.** While a model thinks without streaming, the gateway sends the box a keep-alive every 10 seconds, so a long answer is no longer cut off as an interrupted inference.
- **Out of money says so.** A provider account without credit (402) is reported as that, not as an interrupted inference.

## Updating

- No migration, no binding change. Hosted Servers update in place. L4 Compute needs the 0.0.24 box templates.
