# L4 0.0.18

An Agent draws without an image model being chosen first. No migration.

## Agents

- **Nano Banana by default.** When neither Images nor Avatars has a model, `generate_image` draws with Nano Banana (`google/gemini-2.5-flash-image`) on the Server's first enabled OpenRouter connection, even when that connection's saved models do not list it. A model the Owner chooses for Images or Avatars still comes first. A Server whose OpenRouter key was set before 0.0.17, such as an AfterPrompt Studio Server, can now draw a game's art.

## Updating

- No migration, no binding change. Hosted Servers update in place.
