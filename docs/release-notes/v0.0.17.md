# L4 0.0.17

An Agent draws the art it needs into its checkout, a partner's game is talked through before a box starts, and a game's repository can start from a kit. No migration.

## Agents

- **Images.** A new AI function in **Models → Defaults** draws pictures an Agent asks for while it works, such as a game's sprites, backgrounds and cover. It takes an OpenRouter model that outputs images, such as Nano Banana; without one, Agents use the Avatars model. The Server's own provider key pays for it, as for the Agent's model.
- **`generate_image`.** In a Task's box, an Agent describes the picture, its shape and where to save it. The Server draws it, and the box fetches it once and writes it inside its checkout, never into `.git` or outside it. The picture never enters the conversation or the database.

## Partners

- **Talk first.** `tasks/create` and `tasks/message` take `build`. With `build: false` the Agent answers without a repository or a box, so talking an idea through spends no Compute. The next message with `build: true` gets the Task's repository and its box.
- **A game's files.** `projects/files` lists one folder of a game's repository at a ref, and `projects/file` reads one file's text, up to 512 KB.
- **A starter kit.** `projects/create` takes `files`: up to 200 text files and 1 MB that make the repository's first commit, such as AfterPrompt's game kit.
- **An image model for the art.** A partner's `models/set` also sets Images to an OpenRouter image model, once, and keeps that model among the Server's models.

## Updating

- No migration, no binding change. Hosted Servers update in place.
