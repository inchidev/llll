# L4 0.0.9

The release llll.gg needs to create Servers on L4 Cloud. A Server you run yourself does not change: no database migration, no new binding, no new setting. Take the pre-update backup as usual.

## L4 Cloud

- **A Server can be made in L4's own Cloudflare account.** The installer in `deployment-core` uploads this release into a Workers for Platforms namespace with the Server's own database, files, backups and KV, at `<name>.llll.gg`. Creating one happens on llll.gg from an account; it is coming, not open yet. See [ADR 0008](../adr/0008-server-per-tenant.md).
- **Such a Server runs as `LLLL_RUNTIME=cloud`.** It holds no Cloudflare account token, so Settings → Deployment and Updates say L4 Cloud manages it, and its address is fixed. It answers its control plane only at `/.llll/cloud/scheduled` and `/.llll/cloud/purge-files`, with a secret of its own; every other Server answers 404 there.

## Updating

- Cloudflare: no resource, binding or Durable Object changes.
- VPS and Docker: redeploy the new image as usual.
