# L4 0.4.4

The deploy completion screen turns the installation address into something you keep: open the new installation in the shell right away or copy its URL, so the worker address is stored in the browser's connections before anything depends on it.

## Changes

- The `/deploy` completion screen shows **Open in the shell**, which runs the existing connection check and saves the installation as a bookmark in that browser's Connections.
- A **Copy installation URL** action copies the address, with a short note that this address is the installation's only identifier and other browsers need it again.
