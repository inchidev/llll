# L4 0.3.6

This release puts the documentation, a changelog and a blog on llll.gg, with Markdown copies of every page for agents, and polishes updates, Runs and avatars after the 0.3.4 rollout. Landing, Shell, installer, Server, portable runtime and Docs share **0.3.6**. It stays on the `server-v2` lineage and adds no migrations. Customer Servers update only when their operator chooses an update.

## Docs, changelog and blog on llll.gg

- [llll.gg/docs](https://llll.gg/docs) has user documentation for running and using a Server: getting started, a Cloudflare section (what the installer creates, access, costs, domain, mail, updates, backups and removal), self-hosting on a VPS, Docker and Coolify, Agents and MCP, and guides. Search opens with ⌘K.
- [llll.gg/changelog](https://llll.gg/changelog) has a page for every published release and an RSS feed. [llll.gg/blog](https://llll.gg/blog) is new.
- For agents, every docs, changelog and blog page is also Markdown: add `.md` to its address or request it with `Accept: text/markdown`. `/llms.txt`, `/docs/llms.txt` and `/docs/llms-full.txt` index them. Each page can be copied or opened in Claude or ChatGPT.
- Pages have their own titles, descriptions, canonical addresses and structured data, and there is a sitemap. Unknown addresses on llll.gg now return a 404 page instead of the landing page.

## Updates

- One card shows the installed version, the update's progress (backup → update → verify) and the result. The release picker hides while an update runs, and Cloudflare access is a compact row at the bottom.
- **Load the new interface** waits for the new version to finish downloading, so it no longer reloads into the old interface. Errors show on the card.

## Runs, settings and avatars

- Retry, Stop and both downloads sit in one row under a Run's status. A Run blocked by a disabled or removed Compute Node names the node and links to Compute settings.
- The settings close button stays in view while scrolling.
- The avatar generator opens in a dialog, shows which model draws, and **Use this picture** works. The agent editor previews the picked picture before saving.
- The agent editor's external-agent hint and the installer's Cloudflare text describe the current settings.

## For operators

- Server Previews report `Server-Timing` for D1 and Durable Object waits. It is off for production and customer Servers; see `SERVER_TIMING` in the [preview docs](https://github.com/inchidev/llll/blob/v0.3.6/docs/worker-previews.md#request-timing).

## Update to this release

A Cloudflare Server that keeps Cloudflare access updates from Server settings → Deployment → Updates by itself. A Docker Server updates by its image tag in Coolify or Docker Compose; the VPS installer uses `llll upgrade`.
