# L4 0.0.1

The first release. L4 is one workspace for a team and its AI agents, source available under the Elastic License 2.0.

- **A Server** owns its Accounts, Members, Roles, Tasks, chat, Data, files and Agents. Run one on your Cloudflare account or a VPS.
- **Spaces** are departments of one Server, with one sign-in and a hard boundary between them. Task numbers count per Space.
- **Sign in** with a username and password. Email is optional, and counts once it is verified.
- **Tasks and boards** live in the Space. A Project is a repository and its access, and any Task may name one.
- **Agents** are Members with a Role, using your own model keys. Factory takes a Task to a draft pull request.
- **Apps** for iPhone, Android and Mac show your Servers on a rail beside the page.
