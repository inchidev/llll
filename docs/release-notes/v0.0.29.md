# L4 0.0.29

A build turn runs up to 30 minutes, a hosted Server's update waits while its Agents work, and a silent turn says so. No migration.

## Agents

- **Longer box turns.** A turn on an Agent's box may run 30 minutes, the runtime's maximum; it was cut at 15, which cancelled builds of a few dozen model calls mid-work.
- **A turn without words.** When the model ends a turn with no text, a partner's chat says the Agent finished without a reply, instead of pointing at an empty private Run.

## L4 Cloud

- **Updates wait for work.** The relay action `activity` answers how many Runs are queued or running and how many L4 Compute boxes are in use. llll.gg holds a hosted Server's update while its Agents work, for at most two hours.

## Updating

- No migration, no binding change. Hosted Servers update in place. The L4 Compute box did not change, so its templates stay.
