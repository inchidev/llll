# L4 0.0.30

One failed model call no longer ends an Agent's turn. No migration.

## Agents

- **The gateway asks again.** A model call whose provider fails before anything reached the Agent (a dropped or ended stream, a timeout, 408, 409, 429 or a 5xx) is started again on the Server, up to twice. A call that already streamed, and a refusal such as no credit, fail as before.

## Updating

- No migration, no binding change. Hosted Servers update in place, once their Agents are not working. The L4 Compute box did not change, so its templates stay.
