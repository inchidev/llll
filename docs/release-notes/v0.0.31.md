# L4 0.0.31

Boxes on a small machine can publish and save again. No migration.

## Software Factory

- **A scratch disk that fits.** Publishing a commit and saving an idle box use one scratch disk at a time, which was fixed at 2 GiB. `LLLL_SCRATCH_DISK_BYTES` now sets it, from 256 MiB to 2 GiB (2 GiB by default). On L4 Compute a Small box has 1.4 GB beside its box image and Task disk, so no box there could publish or save; its template takes 768 MiB.

## Updating

- No migration, no binding change. Hosted Servers update in place, once their Agents are not working. L4 Compute needs the 0.0.31 box templates.
