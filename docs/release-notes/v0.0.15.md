# L4 0.0.15

An Agent's box works on a repository in L4, and an Agent made by a partner starts on a strong model. No migration.

## Software Factory

- **A box fetches a repository in L4.** The Compute Node refused the source of a Project whose repository lives in L4 (Artifacts), because it expected a GitHub-style `owner/name`; the box then could not start. A source the Node fetches through its Server now needs only a safe name.
- **A partner's Agent starts on a strong model.** When a partner such as AfterPrompt connects an OpenRouter key, the Server picks the default model from strong families (Claude, GPT-5, Gemini Pro, Qwen3 Coder, Kimi K2, DeepSeek) instead of the newest model OpenRouter lists, which can be a small one. A default the Owner chose stays.

## Updating

- No migration and no binding change. The Compute Node changes: Nodes on a VPS get it with the update; L4 Compute's box templates are made again for this release.
