# L4 0.0.35

Several people can watch one Portal, as a preview the operator turns on. No migration, no binding change.

## Portal

- **Several viewers (preview).** With a Cloudflare Realtime SFU app, up to 16 people watch one Portal: the Mac sends the picture and sound once, and each viewer receives it from the SFU in the size that suits their screen. Nobody controls the window until the host gives control to one viewer; the host can take it back at any time. The Portal's Durable Object makes every SFU call; the app's secret never reaches the Mac or a guest.
- **Off unless turned on.** This has not yet run against Cloudflare's SFU itself, so it needs the operator: set `REALTIME_SFU_APP_ID` and `REALTIME_SFU_APP_TOKEN`, or `PORTAL_SFU_AUTO=1` on a Server that keeps Cloudflare access. Without it a Portal keeps one guest at a time, as in 0.0.34.
- **Relay protocol v2** is negotiated: a Mac that offers it to a Server without an SFU, or to a Server from before this release, is answered as v1 and carries on with one guest. See [ADR 0014](../adr/0014-portal.md), stage 3.

## Updating

- No migration, no binding change.
