# L4 0.0.26

A partner sees a running turn as working, and every turn on a Task sees its images. No migration.

## Partners

- **Working, not waiting.** A Task an earlier turn left in review no longer shows as waiting while a new turn runs, so the partner shows the Agent at work with its live steps. A pending approval still shows as waiting.
- **The Task's images in every turn.** A new turn on a partner's Task is given the Task's image files again, newest first within the image limit, so a screenshot the game started from is seen in later turns too, not only its name.

## Updating

- No migration, no binding change. Hosted Servers update in place. L4 Compute uses the 0.0.26 box templates.
