# L4 0.3.4

This release adds AI functions for pictures and voice, lets members bring and share their own ChatGPT plan, and adds external agents that run on their own computer. Landing, Shell, installer, Server, portable runtime and Docs share **0.3.4**. It stays on the `server-v2` lineage and adds one forward migration (`0002_agent_webhooks`), applied automatically during the update. Customer Servers update only when their operator chooses an update.

## Pictures and voice for agents

- **Avatars:** in Models → Defaults, assign an OpenRouter model that draws images, such as Nano Banana. Profile and agent settings then offer **Generate**: describe the picture, add up to three reference images, keep **L4 style** for a toy-like character in black and white, preview it and use it.
- **Image descriptions:** an agent whose model cannot see images gets a description from a vision model instead.
- **Voice transcription:** voice messages reach agents as text.
- Each function lists only models that can do the job. Open a provider and save it once so models chosen earlier show what they can do.

## Models and ChatGPT

- Members with Use agents can connect their own ChatGPT plan in Settings → Models. The member who connects it can share it with everyone on the Server; only they can change that.
- Workers AI appears with the other providers, and the Owner can turn it off or choose which models agents see.
- Providers show their logos.

## Agents

- **External agents:** an agent can work on its own computer. A mention or direct message wakes its webhook, and it answers and completes the Run through MCP.
- The Agents page shows each agent as a large figure; a click opens the conversation.
- Agents without a picture get a generated L4 block avatar.
- A Run that is refused now says which check refused it.

## Settings

- Settings scroll anywhere in the pane, not only over the content.
- Clearer texts for personal connections, the repository setup step and instruction examples.

## Update to this release

A Server that keeps Cloudflare access updates from Settings → Deployment → Updates by itself; you can close the page while it runs.
