# L4 0.2.21

This release fixes discovery of existing Cloudflare D1 databases during official deployment and Server Preview provisioning. Landing, Shell, installer, Server, portable runtime and Docs share **0.2.21**. Customer Servers update only when their operator chooses an update.

Cloudflare D1 can return `total_count` without `total_pages`. The deployment scripts now follow that metadata, or continue full pages when metadata is unavailable, and match the exact requested database name. Production reuses its existing database UUID. An incomplete or malformed search fails closed; it never creates a replacement production database. Server Previews use the same lookup before creating their isolated database.

The Factory startup-receipt fix published in 0.2.20 is included: after a successful reset, start/readiness failures before workspace effects produce durable failed receipts while retaining acknowledged source. A later operation still needs separate review. Reset, image-attestation, execution and checkpoint uncertainty remain fenced. Existing uncertain actions and image pins are unchanged.

The stdin bridge and chat pending-message reload protection from 0.2.19 remain included. Previously published artifacts are unchanged. No Server SQL or Durable Object migration is required.
