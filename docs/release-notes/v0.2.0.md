# L4 0.2.0

Independent installations now render their own clients inside the official web/PWA/Telegram shell. Local authentication works directly and in embedded mode; the shell receives navigation and server metadata, not session credentials or chat content. Public server links use UUIDv4 IDs assigned by an appended installation migration.

The Cloudflare OAuth installer deploys customer-owned installations, preserves resource identities across retries, encrypts temporary grants and hands them to the installation. Operators must register/configure a public OAuth client and pin the complete deployment artifact by SHA256. VPS deployment remains celld + Compose/Coolify.

The landing reuses the Discoflare website and product demonstrations with L4 branding and the new self-hosting flow. The separate legacy Admin has been removed. iOS/macOS releases remain frozen.

Apply installation migrations in order, preserving existing server IDs and credentials. Back up both installation and server layers before updating. Keep EMBED_ORIGINS restricted to intended hosts. Provider configuration, public OAuth consent and real-device acceptance are distinct from core chat availability.
