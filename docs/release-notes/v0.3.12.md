# L4 0.3.12

This release finishes the Telegram Shell after its first real-device test: it opens full screen on phones, and each Telegram notification arrives once. Landing, Shell, installer, Server, portable runtime and Docs share **0.3.12**. It stays on the `server-v2` lineage and adds no migrations. Customer Servers update only when their operator chooses an update.

## Telegram Shell

- On iOS and Android, [@L4_agent](https://t.me/L4_agent) opens the Shell full screen, clear of Telegram's controls, the notch and the home indicator. A swipe down scrolls the chat instead of closing the app, and Telegram's header and bottom bar match the Shell's black.
- Telegram's launch data no longer stays in the Shell's address after it opens.

## Telegram notifications

- A Server that retried a Telegram notification after losing llll.gg's answer could send it twice. Each delivery now has its own key, and llll.gg sends it once. This needs the Server on 0.3.12; earlier Servers keep working without it.

## Shell

- On phones and in Telegram, **Add a Server** names its tabs Connect, Cloudflare and VPS, so they fit beside the Server rail.

## Update to this release

A Cloudflare Server that keeps Cloudflare access updates from Server settings → Deployment → Updates by itself. A Docker Server updates by its image tag in Coolify or Docker Compose; the VPS installer uses `llll upgrade`.
