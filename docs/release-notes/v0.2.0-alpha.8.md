# L4 0.2.0-alpha.8

This release polishes the standalone Server Client and mobile Shell navigation.

- Show available Client updates in web and embedded Clients, including workers already installing at startup. Offer a retry after stalled activation and recheck unsaved work before a delayed reload. Preserve message drafts across updates.
- Replace the mobile Shell rail with a labelled Server menu so chat and settings use the full screen width. Switching Servers keeps loaded Clients mounted.
- Use a shorter mobile message placeholder while retaining the full conversation label for assistive technology.
- Stack Overview icon and name controls on phones. Show save/reset only for changed names, validate names and preserve unsaved edits during metadata refresh.
- Scroll right-panel tabs into view when selected with the keyboard. Keep settings navigation headings readable when the list overflows.
- Refresh public assets during Shell service-worker installation while retaining normal same-origin credentials.

Verified on desktop and Chrome mobile emulation at 320/390 px, including Overview save/reset, Server name propagation, keyboard tabs and an embedded Client update with a preserved draft. Physical-device verification remains separate.

The official Shell/site updates through Workers Builds from this release's immutable archive. Existing standalone Servers remain pinned until their operator updates them. Clients predating the update banner may need their existing Server tabs closed once for this first upgrade. The `server-v1` schema and Server-local authentication are unchanged. Native iOS/macOS packaging remains frozen.
