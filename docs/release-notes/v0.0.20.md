# L4 0.0.20

An Agent with a wide role works on its Task's box again, and a refused turn says why. No migration.

## Software Factory

- **The whole tool catalog fits a box turn.** A box turn carries every tool the Agent may use, most of them loaded only when it asks for them. The runtime in the box took at most 40, and an Agent with a wide role on a Task's box now has 40 or more (the art tool came in 0.0.17), so its box refused every turn before it started. The runtime and the gateway now take up to 120.
- **Why a turn was refused.** A turn the box cannot take now ends with the field and the issue, such as `(Not a turn this box takes (tools: too_big))`, instead of only "The Agent's box refused this turn". The values never leave the box.

## Updating

- No migration, no binding change. Hosted Servers update in place. L4 Compute and paired Nodes need the 0.0.20 box image.
