# L4 0.2.0-alpha.1

This release starts the clean `server-v1` database lineage. Deploy a fresh Server. Earlier database schemas and backups are not upgrade inputs for this runtime; use their original matching releases when recovering historical data.

- Server is the domain term throughout SQL, HTTP APIs, realtime, permissions, audit events, client state and UI. Each Server owns its local Accounts, Members, Roles, content, files and Durable Objects. The optional Shell connects independent Servers.
- One baseline creates the current schema directly. The runtime requires its schema marker and refuses other populated databases without mutating them. Future migrations append within this lineage.
- Remove mirrored authentication identities, obsolete Agent/runtime and task-assignment columns, old Live state aliases, privileged first-Server mail routing and earlier control-plane compatibility code.
- Server discovery uses API version 2. The Server manifest declares `llll-server-schema-v1`; deployment bundles and release provenance use schema version 3. Earlier contracts are not install choices for this line.
- Keep local login, explicit account linking, local DMs, session revocation and separate backup destinations. Existing Git history, published tags/assets and historical backups are preserved.

Native iOS/macOS packaging remains frozen. Provider credentials remain local to each Server.
