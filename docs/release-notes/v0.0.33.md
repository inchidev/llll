# L4 0.0.33

A request nobody answers no longer keeps a paid box running for hours. No migration.

## Software Factory

- **A request waits 30 minutes for a person.** A network window, a plan or a push used to wait for a decision until its Run's deadline, six hours, and the box held its turn all that time. On L4 Compute that box was billed by the minute. Now a request waits as long as one box turn, 30 minutes. Then it closes, the turn stops saying the Agent waited for an answer, and the box idles and parks. The Agent asks again in its next turn.

## Updating

- No migration, no binding change. Hosted Servers update in place, once their Agents are not working. The box did not change, so the 0.0.32 box templates stay.
