# L4 0.0.2

The Docs now say plainly what works today and what is coming.

- **Today:** create a Server on your Cloudflare account or a VPS and update it when you choose, free, with every feature.
- **Coming:** L4 Cloud, where we host your Server, and apps for iPhone, Android and Mac, which are local builds for now. [Pricing](https://llll.gg/pricing) has the plans.
- **Servers page:** it moved to `/docs/concepts/servers`, and the Docs call a Server an organization.
- **Self-host:** the storage setup in the Compose files uses `aws-cli` 2.39.3.

No schema change. Update from Server settings → Deployment → Updates, or by the image tag on Docker and `llll upgrade` on a VPS.
