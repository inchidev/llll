# L4 0.3.7

This release fills the blog on llll.gg and makes the site easier for agents and crawlers to read. Landing, Shell, installer, Server, portable runtime and Docs share **0.3.7**. It stays on the `server-v2` lineage and adds no migrations. The Server itself is unchanged from 0.3.6, so updating a Server is optional. Customer Servers update only when their operator chooses an update.

## Blog

- [llll.gg/blog](https://llll.gg/blog) has 27 new articles on running a Server of your own, Agents as Members, backups, mail, MCP and leaving hosted workspaces.

## For agents and crawlers

- `/blog.md` and `/changelog.md` list every post and release with a link to its Markdown copy, and `/blog` and `/changelog` return them for `Accept: text/markdown`. Before, only single posts and releases had a Markdown copy.
- The home page answers `Accept: text/markdown` with `/llms.txt`.
- `robots.txt` declares Content Signals: search and AI input are allowed, AI training is not.

## Update to this release

A Cloudflare Server that keeps Cloudflare access updates from Server settings → Deployment → Updates by itself. A Docker Server updates by its image tag in Coolify or Docker Compose; the VPS installer uses `llll upgrade`.
