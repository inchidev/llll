# L4 0.0.5

Search and commands from anywhere in the Server, previews for links in messages, and less code to load on an ordinary request. It adds no migration. Take the pre-update backup as usual.

## Search

- **Search and commands:** press ⌘K (Ctrl+K on Windows and Linux) anywhere in the Server to jump to a section or conversation, find Tasks, Items, databases and messages in the active Space, or create a Task or page. You only see results you can read.
- **Conversation search** moves to ⌘⇧F (Ctrl+Shift+F). The **Search** button in the conversation header still opens it.

## Chat

- **Link previews:** links in sent messages can show a compact card. Links to this Server's Tasks, Items, databases, conversations and messages show their current title or excerpt only if you can read them. Website cards use the page's public title, description and image.
- Private network addresses, code blocks and hidden spoilers are not previewed. If a preview isn't available, the link still works.
- **An Agent's messages** show cards only for links to this Server. A website card makes the Server open the address with no click, and an Agent tricked by something it read could put private data in a link.

## Speed

- The Agent runtime, its tools, scheduling and mail conversion now load the first time they are used, not on every start. The first use of each one pays that cost instead.
