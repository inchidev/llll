# L4 web direction

The user selected an adaptation of discoflare-com, rather than a new landing design. Keep its section composition, interactive Chat/Tasks/Mail/Data preview and useful feature copy. Remove Hosted, the separate Admin, shared identity marketing and speculative remote apps. Use neutral black/white/gray surfaces and one restrained lime accent. Preserve the source repository unchanged.

The product shell contains a narrow rail with installation labels rotated -90 degrees beside their servers. It displays the installation's own client in an iframe. The empty state has one address field and one action. Authentication and content belong to the installation.

The landing answers: what does L4 contain, what does its interface look like, where can I run it, and how do I install it? Cloudflare links to /deploy; VPS links to its Compose/Coolify path. The product does not offer managed hosting. Native iOS/macOS delivery is frozen.

Supplied direction takes precedence over exploring three unrelated visual concepts. Validation will compare the retained landing with the old site at phone/tablet/desktop widths and exercise the shell using two independently served installations. Screenshots inherited from Discoflare are identified as such until replaced by captures of the current L4 interface.
