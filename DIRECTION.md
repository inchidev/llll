# L4 web direction

The user selected an adaptation of discoflare-com, rather than a new landing design. Keep its section composition, interactive Chat/Tasks/Mail/Data preview and useful feature copy. Remove Hosted, the separate Admin, shared identity marketing and speculative remote apps. The latest user correction selects a Vercel-inspired strictly achromatic palette: black, white and gray, with no green. Keep the product content from discoflare-com; use precise rules, small corner radii, strong typographic hierarchy and white primary actions on black. This is an evolution of the existing composition, not three unrelated concepts. Preserve the source repository unchanged.

The product shell contains a narrow rail with installation labels rotated -90 degrees beside their servers. It displays the installation's own client in an iframe. The empty state has one address field and one action. Authentication and content belong to the installation.

The landing answers: what does L4 contain, what does its interface look like, where can I run it, and how do I install it? Cloudflare links to /deploy; VPS links to its Compose/Coolify path. The product does not offer managed hosting. Native iOS/macOS delivery is frozen.

Supplied direction takes precedence over exploring three unrelated visual concepts. Validation will compare the retained landing with the old site at phone/tablet/desktop widths and exercise the shell using two independently served installations. Screenshots inherited from Discoflare are identified as such and displayed in monochrome until replaced by current L4 captures. The new vector mark consists of four upright L glyphs in a two-by-two grid: four independent spaces, one installation. Generate only web/PWA assets; native packages are frozen.

Bundled Geist (SIL OFL 1.1) gives consistent typography across platforms. Monochrome previews crop on narrow phones for readable detail; their caption discloses the inherited sample content. No native packaging or provider behavior changes.
