You use a Server by opening its address in a browser, for example `chat.example.com`. An invitation link opens the same Server. Everything works there: login, conversations, files and Settings.

Each Server has its own Accounts. You sign in to each Server separately, with that Server's Account.

## Add another Server

1. Open a Server you use.
2. Select the Server's avatar at the top of the rail to open the Server menu.
3. Select **Add a Server**.
4. In **Address**, enter the other Server's address, for example `chat.example.com`.
5. Select **Add**.

A rail of Servers then shows at the far left. On a phone, it appears with the navigation drawer or when you are signed out.

Select a Server in the rail to go to it. This is an ordinary page load of another site. The rail shows each Server's name or initial, and no unread counts for other Servers. To hear from a Server while you are elsewhere, turn on [notifications](../guides/notifications.md) there.

## Where the list is kept

Your browser keeps the list on that Server's address, on this device. That Server's own page can read it. No other Server can.

An entry holds an address and a public name. It is not an Account, holds no login and grants no membership.

Lists are not synced. Each Server's list holds only what was added there or accepted there, and each device and browser has its own.

## Add the way back

The first time you go to a listed Server, it learns where you came from and offers **Add the way back?** It shows the address first. Check that you recognize it, because anyone can write a link that offers an address.

Select **Add** to put it on this Server's list, or **Not now** to leave the list as it is. Nothing is added without asking.

## Remove a Server from the list

1. Open the Server menu and select **Add a Server**.
2. Select the **×** next to the Server.

Removing an entry does not delete the Server, your Account or your membership. You can add it again at any time.

## In the iOS, Android and Mac apps

These apps are local builds and are not published. The app keeps this device's list itself and shows it as a rail at the far left, on a phone together with the navigation drawer. **All Servers** in the Server menu opens the full list. A Server's page can't read it.
