title: Notion export is useful. It isn't ownership of your workspace.
description: A ZIP of Markdown and CSV is a start. A workspace you can operate and recover is a different promise.
date: 2026-10-30
author: Inchi
---

Notion made it remarkably easy to put a team wiki, database and project plan in one place. It also makes a revealing distinction possible: you can export content without taking the whole working system with you.

[Notion's export documentation](https://www.notion.com/en-gb/help/export-your-content) describes Markdown exports for pages and CSV for full-page databases, with Markdown for subpages. It also says a database export can include the current view or the default view, not all views at once. Export is real and useful. It's just not the same thing as picking up a running workspace—with every workflow, permission and behavior intact—and operating it elsewhere.

## The ZIP is the start of the work

Once you leave a hosted workspace, someone has to reconstruct what the files meant: which people had access, how the team used the database and which processes depended on the old interface. Portable text is valuable. A plan for operating the system is valuable too.

L4's bet is that a community should be able to run the Server where its conversations, Tasks, Data and Documents live. The software is MIT licensed, and each Server owns its Accounts and local permissions. Backups and recovery are part of the design, with backup storage separate from live files.

That does not make L4 a drop-in Notion replacement. Notion has years of product depth, integrations and familiar workflows. We are not claiming an automatic Notion importer, equivalent databases or a proven one-click migration. Recovery needs its own test on the Server you run; having the source code is not a backup.

## Ask the harder question

Don't just ask whether an app can give you a ZIP. Ask what you need to restore a working team: content, identity, permissions, files and the ability to run the software. Then try it before you need it.

Notion deserves credit for giving users export formats. We want to go further: make the running workspace itself something the community can operate. That is a harder promise, and it is the one L4 is working toward.
