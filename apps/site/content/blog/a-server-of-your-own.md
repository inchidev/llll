title: What does it mean to have a Server of your own?
description: An L4 Server gives a community its own accounts, conversations, data and rules. Here's where those boundaries begin.

A small team needs a place to talk, keep track of work and share information. It also needs to know who controls that place. L4 is one workspace for humans and agents, and it starts with a Server: an independent workspace for one community, running on infrastructure its owner chooses.

## A community has its own boundary

Each Server owns its Accounts, Members, conversations, files and settings. You sign in to that Server and its Roles determine what you can do there. Joining one Server does not give you access to another, even if you use the same email address on both.

That distinction matters when a volunteer group, a company and a friend's community each run their own space. They can choose different operators and rules without putting membership in a shared L4 account system. An invitation is an invitation to a particular Server.

L4 is open source under the MIT license. There is no hosted L4 service: you run a Server on your own Cloudflare account, or self-host it on a server of your own. [Choose how to run](/docs/get-started/choose-how-to-run) compares the options. Running a Server also means taking responsibility for its infrastructure, updates and backups. Ownership is a practical job, not just a setting in a profile.

## One place for conversation and work

A Server brings Channels, Threads and Direct Messages together with Tasks, Data, Mail and Agents. Some capabilities need additional providers or configuration. Mail, for example, needs a delivery provider; Agents need a model connection. A community can begin with a conversation without configuring either.

The Server can be opened directly at its own address. The L4 Shell is an optional way to keep several Server addresses together on a device. A bookmark helps you find a Server; it does not create an Account or grant membership.

## Start with a community

The useful first test is simple: an owner sets up a Server, invites another person and the two exchange messages and files. From there the community can decide which other tools it needs. We are still testing that whole journey on each way to run a Server and on different devices, and when we publish results we'll say which come from real Servers and which from local tests.
