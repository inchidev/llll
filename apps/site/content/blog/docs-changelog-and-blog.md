Until now, the L4 documentation was a handful of cards linking to Markdown files on GitHub. That was enough while L4 was mostly a repository. It isn't enough for someone who just wants to run a Server, so the docs now live at [llll.gg/docs](/docs).

## What's new

- **Docs written for operators and members.** Getting started, a full Cloudflare section (what the installer creates, access, costs, domains, updates, backups and removal), self-hosting on a VPS, Docker and Coolify, Agents and MCP, and guides for Chat, Projects and Tasks, Mail, calls and notifications.
- **A changelog.** Every published release has its own page at [llll.gg/changelog](/changelog), with an RSS feed.
- **This blog**, for things that don't fit in release notes.

## Docs for agents

People increasingly read docs through an assistant, and agents read them on their own. Every docs, changelog and blog page is also plain Markdown: add `.md` to the address, or ask for `Accept: text/markdown`. [llms.txt](/llms.txt) explains what L4 is and points to the [full docs index](/docs/llms.txt).
